# Вопросы и ответы
**1.** ПМ.02 (Разработка и администрирование баз данных) формирует: проектирование БД, написание SQL-запросов, администрирование СУБД, разработку приложений для работы с данными.

**2.** **Python** — простой, быстрая разработка; **MySQL** — надёжная реляционная БД; **tkinter** — встроен в Python, не требует доп. установки. Альтернативы: C# + MSSQL + WinForms, Java + PostgreSQL + JavaFX.

**3.** **ER-диаграмма** — схема "сущность-связь", которая показывает структуру БД: таблицы, их поля и связи между ними. Нужна для проектирования БД до её реализации.

**4.** Типы связей: **1:1** (паспорт-человек), **1:N** (категория-товары), **N:M** (студенты-курсы). *Пример из варианта:* пользователь(1) → заказы(N) — связь 1:N.

**5.** **Git** — система контроля версий. **git commit** — сохраняет изменения локально, **git push** — отправляет их на удалённый сервер (GitHub).

**6.** Выполнить в терминале: `python --version` и `python -c "import tkinter; tkinter._test()"` — откроется тестовое окно.

**7.** Не передавать пароли другим, не загружать сомнительные файлы, использовать антивирус, блокировать экран при уходе, соблюдать правила электробезопасности.

**8.** **127.0.0.1** (localhost) — локальный компьютер, с которого выполняется запрос (адрес для обращения к своему ПК).

**9.** 
```bash
git init
git add имя_файла
git commit -m "описание"
git remote add origin ссылка_на_репозиторий
git push -u origin master
```

**10.** **README.md** описывает проект: его цель, установку, использование, автора — чтобы другие понимали, что это за программа и как с ней работать.
